## 3. Habit loop mapping

| Element | This habit |
|---|---|
| Cue (trigger) | [time / location / preceding action / emotion] |
| Craving (motivation) | [what the user is hoping to feel or get] |

Make it obvious:
- [physical placement - put the cue in line of sight]

- [friction reducers - prep the night before, lay things out, remove decisions]

- [remove the cue for the bad habit, add friction]

## 5. Two-minute version
On the worst day, the only version I will still do is:
[the smallest version of the routine that still counts as showing up]

## 6. Tracking method
- Primary: [calendar X's / journal line / app - pick ONE]
- Backup check-in: [same time every day, even on non-practice days]
- Rule: never miss twice in a row.

## 7. Weekly review (Sunday evening, 5 minutes)
1. Did I show up at least 5 of 7 days? Y / N
2. If N: was the cue reliable? If not, swap to a stronger anchor.
3. Was the routine too big? If yes, shrink until effortless.
4. Is the reward still satisfying? If not, add a new immediate reinforcer.
5. Adjust the plan, do not adjust the person.

## 8. Scaling plan (start this section in week 5, not before)
- Trigger to scale: [X weeks of 5+/7 completion, OR the two-minute version feels boring]
- How to scale: [add ~10%, OR stack a second habit onto a new anchor - never both at once]
